# Real-phone check (once per release)

Run on one iPhone (Safari) and one Android phone (Chrome), plus an older phone if you have one. Takes about an hour. Write the phone, OS version and date at the top, and tick each line. Anything that fails: use the Feedback button and note the phone.

Phone: ____________  OS: ________  Date: ________  Version (Settings › About): ______

## Accounts
- [ ] Create an account with email: birth date, terms and health boxes appear; a birth year under 13 is stopped
- [ ] Sign in with Google; sign out; sign in again
- [ ] Sign in on a second device and see the same data
- [ ] Coach invites an athlete; athlete joins with the code
- [ ] Under-18 athlete: parent account approves; coach can then see their check-ins
- [ ] Delete my account (throwaway account): signed out and can't sign back in

## Program builder
- [ ] Build programs for two different sports and positions; exercises fit
- [ ] Equipment setup "Home": no barbell exercises appear
- [ ] Today's session changes after a low-readiness check-in, and shows what changed
- [ ] Swap an exercise; options make sense
- [ ] Share code: copy on one phone, import on the other

## Form checker
- [ ] Squat side view, bench, jump landing front view: score looks right against what you saw
- [ ] One of the new lifts (push press or trap bar)
- [ ] Rep-by-rep table: tapping a time jumps the video
- [ ] Form report opens and prints / saves as PDF
- [ ] Live coach counts reps on a set of 5
- [ ] Older phone: Settings › Camera speed shows fast mode, and checks finish in reasonable time
- [ ] Sprint timer and jump test on a real clip
- [ ] Camera heart rate

## Coach
- [ ] Today card lists flagged athletes; tapping opens them
- [ ] Mark practice attendance yesterday; the next day the athletes' load includes it
- [ ] Post a quick question; answer it from an athlete phone; the tally updates after sync
- [ ] Reports: testing report, CSV download opens in a spreadsheet, team PDF prints

## App shell
- [ ] Add to home screen; opens full screen
- [ ] Airplane mode: open the app, log a workout; turn it off; it syncs
- [ ] Dark, light and true black; phone's large text setting; no sideways scrolling
- [ ] Feedback button sends (check the feedback table in Supabase)
- [ ] Privacy and Terms links open
